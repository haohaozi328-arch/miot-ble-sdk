# 逐设备实机验证清单

> 目标：对 SDK 覆盖的 10 台设备逐台做米家 App 实机回归。
> 每台记录：结果（✓/✗）、日期、备注（异常现象 / App 版本 / 固件版本）。
>
> 通用前置：
> - 测试手机可上网，米家 App 已登录；关闭「消息免打扰」避免弹窗遮挡
> - ESP32-C3 通过 USB 连接电脑（串口日志看解析结果）；烧录方法见各固件工程
> - App 端取证（可选）：带 xpmod 模块的补丁包，拉取
>   `/sdcard/Android/data/com.xiaomi.smarthome/files/xp_dump/net_plugin*.log`

## A. spec 连接型

### 1. 米家体脂秤 S400（`scale_s400`）—— 基准设备

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1.1 | 米家首页 → 「+」添加设备，扫描到「米家体脂秤 S400」 | 扫描列表出现 |
| 1.2 | 点击绑定 | 绑定成功（REGISTER），设备页出现 |
| 1.3 | 进入设备页 | 状态「已连接」；历史记录可见旧数据 |
| 1.4 | 等一轮自动模拟测量（或上秤触发） | 实时页显示体重数值跳变 → 稳定 |
| 1.5 | 测量完成 | 自动弹出报告页：体脂率/BMI/肌肉量全套；**时间戳为当前时间**、挂在当前使用者名下 |
| 1.6 | 返回设备页看历史列表 | 新记录在列表中（云端入库成功） |

判据：1.5 时间戳正确 = 10.1 work-mode=0 正常分支；时间戳 1970 = 走了访客分支
（检查固件连接复位逻辑）。串口确认 8.1/8.2/1022 帧全部发出。

## B. MiBeacon 广播型（不绑定，直接扫描查看）

> 广播型验证要点：App 扫描页出现设备卡片 → 点开显示实时对象值。
> 全部走 `miot_beacon_frame_v5` 加密广播帧，注意广播间隔与对象轮换分帧。

### 6. 甲醛检测仪（`sensor_hcho`）
扫描出现设备 → 甲醛 (mg/m³) / 温度 / 湿度 / 电量 四值轮换显示且数值与固件一致。

### 7. 门窗传感器2（`sensor_door`）
扫描出现设备 → 开合状态（开/关/超时未关/复位按固件轮换）/ 光照 / 电量显示。

### 8. 人体传感器2（`sensor_motion`）
扫描出现设备 → 移动+光照 / 无人时长 / 按键 / 电量显示。

### 9. 水浸传感器（`sensor_leak`）
扫描出现设备 → 漏水状态（0=正常，>0=漏水按脚本轮换）/ 电量显示。

### 10. 温湿度计3 mini（`thermo_t3m`）
扫描出现设备 → 温度(float32) / 湿度 / 电量显示（float 对象批次 0x4801-0x4803）。
