# 乐天派人在传感器 POP2 固件 —— ESP32-C3

`rhj.sensor_occupy.l730d` / PID **0x5BBA**（pdid 23418）的米家 BLE 广播固件，
从 `occ_adv`（小米人体存在传感器）派生。

- 官方产品库：`bt_bind_style=2`（BLE 直连）、`resolve_type=3`、`bt_match=1`
- spec：`urn:miot-spec-v2:device:occupancy-sensor:0000A0BF:rhj-l730d:1`

## 对象表（由 spec piid 按公式 eid=0x4000|(siid<<10)|(piid-1000) 推导）

| 对象号 | spec | 类型 | 实测 |
|---|---|---|---|
| `0x484E` | 2.1078 存在状态 | u8 枚举(0无人/2微动/3远离/4接近/5静态/6移动/7进入) | ✅ 云端双向 0→6 |
| `0x4805` | 2.1005 光照 | float lux | ✅ 云端双向 50→300 |
| `0x484F` | 2.1079 持续无人 | u8 分钟 | 轮播 |
| `0x4850` | 2.1080 持续有人 | u8 分钟 | 轮播 |
| `0x100A` | 电量 | u8 % | 标准对象，轮播 |

★与 occ_adv 的差异：持续时长 piid 是 1079/1080（occ 是 1082/1081），
存在状态枚举值是 0/6（occ 是 0/1）。照抄 occ 会导致云端不认。

## 实测（2026-11-25）

1. 米家「+ → 添加设备」发现「乐天派人在传感器POP2」→ 3/3 绑定
2. 云端记录：did `blt.3.1qvp3ilks4000` / MAC `10:00:3B:CE:75:03`
3. 设备页完整渲染：无人存在 / 50 lux / 1分钟前更新 / 人体活动状态 / 光照强度
4. 双向验证（不碰手机，云端实时读）：
   - 串口 `presence 6` → 云端 `2.1078` = **6**
   - 串口 `lux 300` → 云端 `2.1005` = **300**

## 编译 / 烧录

```bash
cd esp32/occ_pop2_adv
idf.py build
idf.py -p COM36 flash        # 不要 erase-flash（丢绑定身份）
```

## 串口命令

| 命令 | 作用 |
|---|---|
| `presence 0\|6` | 无人 / 有人移动，触发 0x484E 连发 3 帧 |
| `lux N` | 光照 lux，触发 0x4805 |
| `info` | PID / 绑定 / 状态 |

BOOT 键：短按切换有人/无人；双击切光照档位；长按 5s 恢复出厂。

## 工程来源

从 `occ_adv` 派生：骨架（GATT + ECDH + MiBeacon2 + 按键语义）沿用，
换 PID / MAC / NVS 命名空间 / 持续时长对象号 / 状态枚举；新增串口命令便于云端双向验证。
