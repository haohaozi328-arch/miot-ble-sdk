# 领普人体存在传感器 ES3 电池款固件 —— ESP32-C3

`linp.sensor_occupy.es2` / PID **0x50FB**（pdid 20731）的米家 BLE 广播固件，
从 `occ_pop2_adv`（乐天派人在传感器POP2）派生。

- 官方产品页：产品 ID 20731，厂商 linptech，蓝牙协议、需网关，2024-10 发布
- spec：`urn:miot-spec-v2:device:occupancy-sensor:0000A0BF:linp-es2:1`（released）
- ★产品名叫 ES3，型号却是 es2（官方数据如此，产品页截图与 miot-spec 双重确认）

## 对象表（由 spec piid 按公式 eid=0x4000|(siid<<10)|(piid-1000) 推导）

| 对象号 | spec | 类型 | 说明 |
|---|---|---|---|
| `0x484E` | 2.1078 存在状态 | u8 枚举(0无人/1~255有人) | ★与 POP2 差异：POP2 是 0/6，ES3 只有 0/1 |
| `0x4805` | 2.1005 光照 | float lux | |
| `0x484F` | 2.1079 持续无人 | u8 分钟 | 轮播 |
| `0x4850` | 2.1080 持续有人 | u8 分钟 | 轮播 |
| `0x100A` | 电量 | u8 % | 标准对象，轮播 |

HA 侧（XiaomiGateway3 devices.py 20731 项）还用到 4.1003 电量、5.1018 自定义距离、3.1 指示灯。

## 编译 / 烧录

```bash
cd esp32/occ_es3_adv
idf.py build
idf.py -p COM36 flash        # 不要 erase-flash（丢绑定身份）
```

## 米家添加

米家 → **+** → **添加设备** → 发现「领普人体存在传感器ES3」→ 点卡片绑定。
派生 MAC `10:00:3B:CE:76:02`（BASE_MAC_B4=0x76，与 occ_adv=74 / pir2s=73 / pop2=75 不冲突）。

## 实测（2026-11-25）

1. 米家「+ → 添加设备」发现「领普人体存在传感器ES3」→ 绑定成功
2. 设备页完整渲染：无人/有人状态、50 lux 光照、感应记录、光照记录、感应设置
3. 感应记录（云端认可）：有人/无人即时切换、「有人 2 分钟 / 无人 2 分钟」时长条件
   ——0x484E 状态、0x4805 光照、0x484F/0x4850 时长全部上云双向
4. 串口命令验证：`presence 0|1` / `lux N` / `batt N` / `info`

## 串口命令

| 命令 | 作用 |
|---|---|
| `presence 0\|1` | 无人 / 有人，触发 0x484E 连发 3 帧 |
| `lux N` | 光照 lux，触发 0x4805 |
| `batt N` | 电量 %，触发 0x100A |
| `info` | PID / 绑定 / 状态 |

BOOT 键：短按切换有人/无人；双击切光照档位；长按 5s 恢复出厂。

## 工程来源

从 `occ_pop2_adv` 派生：骨架（GATT + ECDH + MiBeacon2 + 按键语义）沿用，
换 PID / MAC / NVS 命名空间 / 广播名（ES3BB）/ 存在状态枚举（0/6→0/1）。
新增 `batt` 串口命令便于电量云端双向验证。
